Jak to działa

Lokalny gateway OAuth łączy Twoją subskrypcję ChatGPT z Book Factory. Uruchamiasz go raz — potem w Ustawieniach wklejasz token i wybierasz model. Generujesz książki w ramach swojego planu ChatGPT bez oddzielnych rachunków za tokeny.

1
Zainstaluj i uruchom gateway OAuth
docker-compose up -d
Gateway startuje automatycznie jako serwis Dockera na porcie 8765. Jednorazowa konfiguracja.
2
Zaloguj się kontem ChatGPT w przeglądarce
Otwórz stronę autoryzacji →
Strona logowania ChatGPT/OpenAI. Zaloguj się istniejącym kontem Plus/Pro/Codex.
3
Skopiuj OAuth token i wklej poniżej
Po autoryzacji gateway pokazuje token. Wklej go w pole poniżej → Zapisz → gotowe.

Jak działają ustawienia
• OAuth (ChatGPT) — gateway startuje automatycznie przez docker-compose up. Nie trzeba nic instalować — tylko zalogować się przez przeglądarkę i wkleić token.
• Provider do generowania — wybór „tylko X" oznacza, że aplikacja nie próbuje innych API. Tryb „Automatycznie" zaczyna od OAuth (jeśli token ustawiony).
• Wartości wpisane tutaj nadpisują wartości z pliku .env dla Twojego konta.
• Jeśli pole jest puste, aplikacja używa wartości z .env.
• Klucze i tokeny są przechowywane w lokalnej bazie SQLite — nie są wysyłane nigdzie indziej.
• Testuj provider — wysyła żądanie testowe bez zapisywania. Błąd 401 = token wygasł, odśwież przez localhost:8765/auth.
